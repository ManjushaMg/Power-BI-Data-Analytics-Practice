# Power-bi-dashboard-project
Power-bi-dashboard-project

Sales Analysis

This project analyses sales data using Excel and Power BI to find trends and improve business decisions.
 
 Tools Used
•	Microsoft Excel
•	Power BI  

 Dataset
Source: https://docs.google.com/spreadsheets/d/10ysAN7Dlcd7gr4i_-UE496I_hIJbW_IE/edit?usp=drive_link&ouid=105783269287836040033&rtpof=true&sd=true

Data Contains: Order date, Item type, Units sold, Region, Country etc

Steps Followed 
Cleaned data in Excel (e.g., removed blanks, formatted columns) 
Used Excel formulas and Pivot Tables for basic analysis 
Imported cleaned data into Power BI 
Built dashboards using charts, slicers, and KPIs

Key Insights
1.	Strong overall sales performance
2.	Sales were highest in Q1
3.	Sub Saharan Africa And Europe are the leading regions
4.	North America has the lowest contribution
5.	Fruits and Baby food have high unit volumes
6.	Strong overall sales performance
